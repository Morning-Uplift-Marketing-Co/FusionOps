TECHNICAL FOUNDATION
================================================================================

Core Patterns:

  1. Immutability Pattern
     ✓ All validators return immutable result objects
     ✓ Never throw exceptions
     ✓ Orchestrator collects all failures before deciding

  2. Orchestrator Pattern
     ✓ QualityChecker.validate(html) — single entry point
     ✓ Sequential validation: viewport → pixels → astro → ads → lighthouse
     ✓ Aggregated results with severity levels

  3. Integration Point
     ✓ Quality checks run AFTER AntiFingerprint.transform()
     ✓ Validates fingerprinted output (what users see)
     ✓ Critical failures block deploy, warnings log only

  4. Performance Optimization
     ✓ Pre-compiled regex patterns (Astro leak detection)
     ✓ Whitelist safe Astro builtins (DEV, PROD, SSR)
     ✓ Line number context to minimize false positives

  5. Lighthouse Strategy
     ✓ Local execution (offline, no API rate limits)
     ✓ Chrome launcher with --headless flag
     ✓ 120-second timeout
     ✓ PageSpeed API fallback (advisory-only)

================================================================================
KEY DECISIONS
================================================================================

1. Quality checks are DEPLOY GATES (not advisory)
   - Critical failures block deploy with clear error messages
   - Warnings surface non-blocking issues
   - Enables fail-fast deployment safety

2. Integration happens post-fingerprinting
   - Validates what users will actually see
   - Catches fingerprinting issues before deploy
   - Enables safe caching and redeploy verification

3. Lighthouse runs locally by default
   - Avoids API rate limits
   - No rate limit concerns for high-volume deployments
   - PageSpeed API fallback for offline environments

4. Validators never throw
   - Orchestrator collects all failures atomically
   - Enables clear error aggregation
   - Follows immutable patterns from project rules

5. Backward compatibility is critical
   - ~15 existing templates must pass without new failures
   - Plan 04 regression tests ensure no breakage
   - Validator thresholds adjusted if needed
