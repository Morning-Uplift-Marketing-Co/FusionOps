**Safe Jitter Range:**
- Research literature suggests 500-2000ms safe
- Phase 3 conservative approach: 50-500ms (still effective, lower risk of pixel loss)

**SendBeacon API:**
- Modern standard (95%+ browser support)
- Survives page unload (critical for conversions)
- Returns boolean (true = queued, false = failed)
- Graceful fallback: if sendBeacon not supported, use fetch

**Deterministic Seeding:**
- Same siteId → same jitter delays every time
- Ensures reproducible behavior across redeploys

**Common Pitfall 2: Tracking Pixel Loss**
- Solution: Use sendBeacon (survives unload)
- Solution: Conservative jitter range (50-500ms, not 500-2000ms)
- Solution: Fire pixel on page load, not just beforeunload
- Measurement: <2% loss acceptable (Phase 3 alpha will verify)

```javascript
import crypto from 'crypto';
import seedrandom from 'seedrandom';

export class NetworkRandomizer {
  /**
   * Transform HTML by injecting timing jitter into pixel fires
   * Phase 3 Vector 2: Network behavior randomization
   * @param {string} htmlContent - Raw HTML with tracking pixels
   * @param {string} siteId - Deployment site ID (for seeding)
   * @param {Object} options - Configuration {min: 50, max: 500}
   * @returns {{html: string, jitterApplied: boolean}}
   */
  static transform(htmlContent, siteId, options = {}) {
    const { min = 50, max = 500 } = options;

    // Validate range
    if (min < 0 || max > 2000 || min > max) {
      throw new Error(`Invalid jitter range: min=${min}, max=${max}`);
    }

    // Deterministic seeding: same siteId → same jitter pattern
    const seed = crypto.createHash('sha256')
      .update(siteId + 'network-randomization')
      .digest('hex');
    const rng = seedrandom(seed);

    // Generate jitter wrapper script to inject into HTML
    // This script wraps window.fetch and navigator.sendBeacon
    const jitterScript = `
(function() {
  const MIN_JITTER = ${min};
  const MAX_JITTER = ${max};

  // Wrap navigator.sendBeacon for pixel fires
  const originalSendBeacon = navigator.sendBeacon;
  navigator.sendBeacon = function(...args) {
    const jitter = Math.floor(Math.random() * (MAX_JITTER - MIN_JITTER + 1)) + MIN_JITTER;
    setTimeout(() => {
      try {
        return originalSendBeacon.apply(navigator, args);
      } catch (err) {
        console.error('sendBeacon failed:', err);
      }
    }, jitter);
    return true; // Return immediately (beacon queued)
  };

  // Wrap fetch for additional pixel flexibility
  const originalFetch = window.fetch;
  window.fetch = function(...args) {
    const jitter = Math.floor(Math.random() * (MAX_JITTER - MIN_JITTER + 1)) + MIN_JITTER;
    return new Promise((resolve, reject) => {
      setTimeout(() => {
        originalFetch.apply(window, args).then(resolve).catch(reject);
      }, jitter);
    });
  };
})();
    `;

    // Inject jitter script into HTML head (before any tracking pixels)
    const headMatch = htmlContent.match(/<\/head>/i);
    if (!headMatch) {
      // No head tag, inject before first script
      const scriptMatch = htmlContent.match(/<script/i);
      if (scriptMatch) {
        return {
          html: htmlContent.substring(0, scriptMatch.index)
            + `<script>${jitterScript}</script>`
            + htmlContent.substring(scriptMatch.index),
          jitterApplied: true
        };
      }
      // No head or scripts, inject in body
      return {
        html: htmlContent.replace(/<\/body>/i, `<script>${jitterScript}</script></body>`),
        jitterApplied: true
      };
    }

    // Inject into head
    const beforeHead = htmlContent.substring(0, headMatch.index);
    const afterHead = htmlContent.substring(headMatch.index);
    return {
      html: beforeHead + `<script>${jitterScript}</script>` + afterHead,
      jitterApplied: true
    };
  }
}
```

2. Key implementation details:
   - Jitter range: 50-500ms (conservative, safe for attribution)
   - Seed with crypto.createHash + seedrandom
   - Wrap both sendBeacon and fetch
   - Return immediately for sendBeacon (true), but execute jitter internally
   - Error handling: try/catch for sendBeacon failures
   - Inject as early as possible in HTML (head before other scripts)
