### Task 1: Correlate Detection Timeline with Fingerprinting Vectors

**Objective:** Determine which randomization strategies were most/least effective by correlating fingerprinting vectors applied to each domain with its detection timeline.

**Acceptance Criteria:**
- [ ] Create analysis script `scripts/alpha-analyze-vectors.js` that:
  - Reads domains.json (siteId, template, seed applied to each domain)
  - Reads monitoring-summary.json (days-to-flag per domain)
  - Reads AntiFingerprint.js documentation (6 transform strategies: class names, IDs, data attributes, aria labels, meta tags, structural)
  - Correlates vectors → detection timeline:
    - Group domains by template type: Astro, Vite/React, static HTML
    - For each group, calculate avg/median/std-dev days-to-flag
    - Compare template types: which was most resilient?
    - Identify early-detected domains vs. late-detected vs. still-active
    - Analyze which domains applied all 6 vectors vs. subset
  - Output: `.planning/alpha-test/vector-correlation.json`
    ```json
    {
      "by_template": {
        "astro": {
          "domain_count": 2,
          "avg_days_to_flag": 8,
          "median_days_to_flag": 8,
          "still_active": 0,
          "flagged_early": 0,
          "flagged_late": 2
        },
        "vite_react": { ... },
        "static_html": { ... }
      },
      "by_vector_count": {
        "6_vectors": {
          "domain_count": 5,
          "avg_days_to_flag": 12
        },
        "3_vectors": { ... }
      },
      "resilience_ranking": [
        { "vector": "structural_variation", "impact": "high", "evidence": "..." },
        { "vector": "css_class_randomization", "impact": "medium" },
        ...
      ]
    }
    ```
- [ ] Analyze detection patterns:
  - Did any domains evade detection for full 28 days (resilient fingerprinting)?
  - Did detection happen clustered in specific date ranges?
  - Were suspensions (critical) different from flags (medium)?
  - Did behavioral patterns emerge: e.g., "Astro templates detected by day 5 consistently"?
- [ ] Document confidence levels:
  - High confidence: vector impact if >70% correlation with detection timeline
  - Medium: 40-70% correlation
  - Low: <40% (insufficient data or vector mix confounded)

### Task 2: Identify Gaps & Recommend Additional Vectors

**Objective:** Determine if current HTML/CSS randomization alone is sufficient or if additional vectors needed.

**Acceptance Criteria:**
- [ ] Classify findings into two scenarios:

  **Scenario A: HTML/CSS Randomization Sufficient** (if avg days-to-flag >14 and >30% still-active)
  - Current 6 vectors (class names, IDs, data attributes, aria labels, meta tags, structural) provide adequate evasion
  - Recommend Phase 3 optimization focus: improve fingerprinting determinism, reduce false positive detections
  - Risk: Low (evasion mechanism proven effective)

  **Scenario B: Additional Vectors Needed** (if avg days-to-flag <10 or <5% still-active)
  - Current vectors insufficient; Google Ads detecting via other mechanisms (JavaScript behavior, network patterns, etc.)
  - Recommend Phase 3 extensions: add JS behavioral randomization, network timing variation, request pattern obfuscation
  - Risk: High (evasion mechanism partially compromised; requires significant expansion)

- [ ] Document candidate vectors for Phase 3 if Scenario B:
  - **JavaScript Obfuscation:** Randomize variable names, function call order, timing patterns
  - **Network Behavior Randomization:** Vary request timing, order, payload size (safe limits)
  - **Browser Fingerprint Spoofing:** Randomize user agent, canvas fingerprint, WebGL strings (via iframe if available)
  - **Event Listener Randomization:** Randomize event names, handlers, tracking pixel triggers
  - **Cookie Jar Randomization:** Clear/refresh tracking cookies at intervals, simulate user sessions
  - **Mouse/Keyboard Emulation:** Simulate organic user interaction patterns (high effort, lower ROI)

  For each candidate, estimate:
  - Effort: days to implement
  - Risk: detection evasion improvement % (if known from literature)
  - Blast radius: likelihood of breaking template functionality
  - Cost: infrastructure impact (additional processing, storage, bandwidth)

- [ ] Create Phase 3 roadmap if gaps identified:
  - Prioritize vectors by effort-to-impact ratio
  - Schedule research phase: literature review on latest detection vectors
  - Estimate Phase 3 timelines for implementation

**Success Metric:** Scenario A or B classified; gap analysis completed; Phase 3 recommendations (if needed) documented

**Read First:**
- `.planning/alpha-test/vector-correlation.json` (from Task 1)
- `src/services/AntiFingerprint.js` (current 6 vectors)
- Research notes on Google Ads detection mechanisms (if available in notes or comments)
