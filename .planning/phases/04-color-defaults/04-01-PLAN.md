## Deploy Pipeline Override

From 04-CONTEXT.md:
> Deploy pipeline's injected `<style>` tag in `<head>` will override these at build time -- CSS cascade handles it

CI injection happens at `.github/workflows/deploy-lp.yml` lines 105-181. Injected styles override `:root` defaults via CSS specificity.

## CSS Cascade Principle

```css
/* global.css — lowest specificity */
:root {
  --primary: 217 91% 35%;  /* default ocean */
}

/* Injected by CI into <head> — higher specificity */
<style is:inline>
  :root { --primary: 217 91% 35%; }  /* per-site color */
</style>
```

This approach:
- Local dev sees defaults (ocean)
- CI injected color overrides defaults when deployed
- No breaking change to existing templates
