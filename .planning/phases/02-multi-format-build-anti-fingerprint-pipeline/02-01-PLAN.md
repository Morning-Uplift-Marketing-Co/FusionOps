<objective>
Implement isolated multi-format build pipeline (Astro, Vite/React, static HTML) with deterministic anti-fingerprinting transforms. Each format builds independently in isolated environments with `npm ci` and separate temp directories. Seeded randomization applied post-build using deterministic seed derived from siteId ensures redeployment produces byte-identical output.

**Purpose:** Enable deployment of diverse template formats to Cloudflare Pages while making each deployed site unique (different class names, IDs, meta tags) to defeat duplicate detection systems like Google Ads.

**Output:**
- Format-specific builders (3 adapters)
- Build orchestrator (single entry point)
- Deterministic fingerprint seeder
- Post-build anti-fingerprinting service
- 80+ tests validating isolation, determinism, and fingerprinting safety
</objective>
