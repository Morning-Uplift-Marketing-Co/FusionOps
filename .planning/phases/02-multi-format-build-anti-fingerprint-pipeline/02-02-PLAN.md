- Fingerprint seeder (deterministic RNG + string generation)

- 30+ tests validating determinism, fingerprint safety, and no function breakage

  <name>Task 2.1: Implement fingerprint-seeder with deterministic RNG</name>
  <files>src/utils/fingerprint-seeder.js</files>
  <action>
Create fingerprint-seeder.js with three exports:

**1. createDeterministicRng(siteId, namespace = 'default')**
   - Use Node.js crypto: const hash = crypto.createHash('sha256').update(`${siteId}:${namespace}`).digest('hex')
   - Extract seed from hash: const seed = parseInt(hash.substring(0, 10), 16)
   - Import seedrandom: const seedrandom = require('seedrandom')
   - Return seeded instance: return seedrandom(String(seed))
   - Type: returns object with .random() → [0, 1) float
   - Test: Same (siteId, namespace) ALWAYS produces same sequence

**2. generateDeterministicString(siteId, namespace, length = 8, charset = 'abcdefghijklmnopqrstuvwxyz0123456789')**
   - Create RNG: const rng = createDeterministicRng(siteId, namespace)
   - Map random() to charset: return Array(length).fill(0).map(() => charset[Math.floor(rng.random() * charset.length)]).join('')
   - Test: Same inputs always produce same string

**3. createClassNameMap(siteId, originalClasses = [])**
   - Input: array of class names extracted from HTML
   - For each class: check if it's Tailwind utility (hover:, md:, lg:, etc.) or third-party (data-ga-, analytics-)
   - Whitelist patterns: /^(hover|focus|active|md|lg|xl|sm|dark|light):|^data-(ga|hotjar|gtag|fb)/
   - Whitelisted classes → unchanged
   - Custom classes → replace with `x-${generateDeterministicString(siteId, classOriginal, 8)}`
   - Return map: {originalClass: mappedClass, ...}
   - Test: Whitelist respected, no collisions, deterministic

Keep file < 200 lines. Use only Node.js built-ins (crypto) + seedrandom npm package.

<task type="auto">
  <name>Task 2.2: Implement AntiFingerprint service with post-build transforms</name>
  <files>src/services/AntiFingerprint.js</files>
  <action>
Create AntiFingerprint.js with static method:

**AntiFingerprint.transform(builtHtmlPath, siteId)**
   - Input: path to built HTML file (from TemplateBuilder output)
   - Return: Promise<{success: boolean, transformedPath: string, transforms: {count: number}}>

Implementation (use cheerio for safe DOM manipulation):
```javascript
const cheerio = require('cheerio');
const { createDeterministicRng, generateDeterministicString, createClassNameMap } = require('../utils/fingerprint-seeder');

static async transform(builtHtmlPath, siteId) {
  // Read built HTML
  const html = fs.readFileSync(builtHtmlPath, 'utf-8');
  const $ = cheerio.load(html);
  let transformCount = 0;

  // Transform 1: Class name randomization
  // Extract all classes, build map, replace
  // Whitelist: Tailwind + third-party, randomize custom
  transformCount += transformClassNames($, siteId);

  // Transform 2: ID randomization (data-*, id attributes)
  // Find all id= and data-*= attributes
  // Randomize custom IDs (preserve third-party markers)
  transformCount += transformIds($, siteId);

  // Transform 3: Aria label variation
  // Find aria-label attributes, add variation
  transformCount += transformAriaLabels($, siteId);

  // Transform 4: Meta tag variation
  // Vary generator, description, OG tags
  transformCount += transformMetaTags($, siteId);

  // Transform 5: Structural variation
  // Add/remove whitespace, vary comment placement, reorder non-critical attributes
  transformCount += transformStructure($, siteId);

  // Write transformed HTML
  const transformedHtml = $.html();
  fs.writeFileSync(transformedPath, transformedHtml, 'utf-8');

  return { success: true, transformedPath, transforms: { count: transformCount } };
}
```

**Helper functions (keep each < 50 lines):**

1. **transformClassNames($ , siteId)** — Map classes using createClassNameMap
2. **transformIds($ , siteId)** — Randomize custom IDs, preserve data-ga-*, data-fb-*, etc.
3. **transformAriaLabels($ , siteId)** — Append deterministic suffix to aria-label values
4. **transformMetaTags($ , siteId)** — Vary og:title, description, generator tag
5. **transformStructure($ , siteId)** — Add formatting whitespace, vary attribute order

**Key safeguards:**
- Never remove script tags or event handlers
- Preserve onclick, data-value, data-* attributes used by JS
- Only randomize display-layer attributes (class, visual data-*, aria-label, meta)
- Test that onclick handlers still work post-transform

Keep file < 300 lines. Use cheerio for all DOM manipulation (no regex on HTML).
