# Determinism Strategy

To prove determinism across 3+ builds:
1. Build template once with siteId 'test-site-123' → output1.html
2. Build identical template again with same siteId → output2.html
3. Build third time → output3.html
4. Verify: md5(output1) === md5(output2) === md5(output3)
5. Verify: byte-by-byte comparison shows zero differences

If determinism fails, debug: check RNG seeding, verify no timestamps in output, verify no random file ordering in cheerio transform
