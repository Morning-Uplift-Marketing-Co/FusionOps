**E2E Test Scenarios:**

1. **PREV-01: Live Preview with Variable Injection**
   - Scenario: User enters brand/color/copy in wizard, navigates to Review, opens preview
   - Steps:
     - Fill in StepBrand with brand name "Test Company"
     - Fill in StepColor with primary color "#ff0000"
     - Fill in StepCopy with copy text "Welcome"
     - Navigate to StepReview
     - Click Preview button
     - Verify: iframe renders with all variables injected
   - Assertions:
     - iframe srcDoc contains "Test Company"
     - iframe srcDoc contains "#ff0000" (or CSS variable applied)
     - iframe srcDoc contains "Welcome"
     - No template re-upload needed

2. **PREV-02: Viewport Toggle**
   - Scenario: User toggles between mobile and desktop viewports
   - Steps:
     - Open preview modal (from PREV-01 above)
     - Click viewport toggle to "📱 Mobile"
     - Verify: iframe width = 320px, height = 640px
     - Verify: template CSS media queries trigger (mobile layout visible)
     - Click viewport toggle to "🖥️ Desktop"
     - Verify: iframe width = 1024px, height = 768px
     - Verify: template CSS media queries trigger (desktop layout visible)
   - Assertions:
     - iframe style.width changes: "1024px" ↔ "320px"
     - iframe style.height changes: "768px" ↔ "640px"
     - Template layout visually different (mobile = stacked, desktop = grid)
     - No re-rendering of template HTML (same srcdoc content)

3. **PREV-03: Real-Time Variable Preview with Debounce**
   - Scenario: User changes variables and preview updates in real-time
   - Steps:
     - Open preview modal (from PREV-01 above)
     - Return to StepBrand
     - Change brand name to "Updated Company"
     - Return to StepReview
     - Open preview again
     - Verify: preview shows updated brand name
     - Measure: time from variable change to preview update < 1 second
   - Assertions:
     - usePreviewDebounce detects config change
     - Preview regenerates with new config
     - Debounce prevents excessive generation (only one call after 400ms)
     - Update latency < 1 second

4. **PREV-04: Pre/Post Fingerprint Comparison**
   - Scenario: User views pre and post fingerprint versions
   - Steps:
     - Open preview modal (from PREV-01 above)
     - Click "Fingerprint Comparison" tab
     - Verify: DiffViewer renders
     - Verify: Original HTML visible on left
     - Verify: Fingerprinted HTML visible on right
     - Verify: Diff highlighting shows changes (CSS classes, IDs)
     - Verify: Summary shows added/removed counts
   - Assertions:
     - DiffViewer component renders
     - CSS class names randomized: btn-primary → btn-fp-xyz
     - ID randomization: form-1 → form-fp-abc
     - Data attributes unchanged (Voluum tracking preserved)
     - Summary counts > 0 (some changes detected)

**Test Framework: Playwright** (if full browser testing needed)
```javascript
import { test, expect } from '@playwright/test';

test.describe('Preview E2E', () => {
  test.beforeEach(async ({ page }) => {
    // Navigate to wizard
    await page.goto('http://localhost:3000/wizard');
  });

  test('PREV-01: Preview renders with variable injection', async ({ page }) => {
    // Fill form
    await page.fill('input[name="brand"]', 'Test Company');
    await page.fill('input[name="primaryColor"]', '#ff0000');

    // Navigate to Review
    await page.click('button[name="next"]');
    await page.click('button[name="next"]');

    // Open preview
    await page.click('button:has-text("Preview")');

    // Verify iframe content
    const iframeElement = await page.$('iframe[title="Preview"]');
    const frameHandle = await iframeElement.contentFrame();
    const content = await frameHandle.content();

    expect(content).toContain('Test Company');
    expect(content).toContain('#ff0000');
  });

  test('PREV-02: Viewport toggle works', async ({ page }) => {
    // ... setup ...

    // Open preview
    await page.click('button:has-text("Preview")');

    // Get initial width
    const iframeElement = await page.$('iframe[title="Preview"]');
    let width = await iframeElement.evaluate(el => el.style.width);
    expect(width).toBe('1024px'); // Desktop default

    // Toggle to mobile
    await page.click('button:has-text("Mobile")');
    width = await iframeElement.evaluate(el => el.style.width);
    expect(width).toBe('320px');

    // Toggle back to desktop
    await page.click('button:has-text("Desktop")');
    width = await iframeElement.evaluate(el => el.style.width);
    expect(width).toBe('1024px');
  });

  test('PREV-03: Real-time preview on variable change', async ({ page }) => {
    // ... setup ...

    // Open preview
    await page.click('button:has-text("Preview")');
    const startTime = Date.now();

    // Change variable in another tab
    await page.click('button:has-text("← Back")');
    await page.fill('input[name="brand"]', 'Updated Company');
    await page.click('button:has-text("Next")');

    // Reopen preview
    await page.click('button:has-text("Preview")');
    const endTime = Date.now();

    // Verify
    const iframeElement = await page.$('iframe[title="Preview"]');
    const frameHandle = await iframeElement.contentFrame();
    const content = await frameHandle.content();

    expect(content).toContain('Updated Company');
    expect(endTime - startTime).toBeLessThan(1000); // < 1 second
  });

  test('PREV-04: Fingerprint comparison shows diffs', async ({ page }) => {
    // ... setup ...

    // Open preview
    await page.click('button:has-text("Preview")');

    // Switch to comparison tab
    await page.click('button:has-text("Fingerprint Comparison")');

    // Verify DiffViewer
    await expect(page.locator('text=Original')).toBeVisible();
    await expect(page.locator('text=Fingerprinted')).toBeVisible();

    // Check for diff highlighting
    const addedText = await page.locator('.diff-added').first();
    expect(await addedText.isVisible()).toBe(true);
  });
});
```
