# Phase 05: Tracking Verification

## Objective
Implement reliable, cross-subdomain tracking by migrating from `sessionStorage` to 30-day First-party Cookies. Ensure the tracking pixel operates flawlessly (resolving the recent regression), and guarantee that the Voluum script matches the new spec and fires first. Finally, implement a Puppeteer-based automated verification network check.

## Requirements Addressed
- **TRK-01**: Voluum dtpCallback injects and fires correctly (reads VOLUUMDOMAIN from env)
- **TRK-02**: GCLID/clickid captured to sessionStorage (changed to cookie per D-03/D-04) and passed through to apply page
- **TRK-03**: First-party pixel (fpPixel) injects and fires pageview + events on deployed site

## Tasks

<task>
<action>

1. Replace `VOLUUM_HEAD_SNIPPET` entirely. The new snippet must include the explicit `delegate-ch` meta tags and the `link.scratchpayeasy.com` reference. It must be injected *at the very beginning* of the `<head>` tag.
