## Milestone Overview

**LP Factory v1.0** delivers the complete template import, multi-format build, and quality validation pipeline. Production ready for importing Astro/Vite/HTML templates from bolt.new/Loveable, injecting brand variables correctly, and deploying to Cloudflare with unique fingerprinting to evade duplicate-site detection.

**Critical Accomplishments:**
1. ✓ **Fixed Astro env var injection** — `PUBLIC_*` variables now reach deployed sites instead of fallback expressions
2. ✓ **Multi-format build pipeline** — Astro, Vite/React, static HTML each build independently with isolated npm environments
3. ✓ **Deterministic anti-fingerprinting** — Same siteId → byte-identical output; CSS class names, DOM IDs, meta tags randomized per deploy
4. ✓ **Quality validation gates** — Viewport, tracking pixels, Astro leak detection, Google Ads markers, Lighthouse 95+ enforcement
5. ✓ **Capability-aware wizard** — Auto-detects template features; shows/hides wizard steps based on capabilities

**Not Included (Phase 4 — Deferred to v1.1):**
- Live preview modal with real-time variable injection
- Mobile/desktop viewport toggle
- Pre/post-fingerprint HTML comparison

## Technical Decisions

| Decision | Rationale | Implementation |
|----------|-----------|-----------------|
| Multi-level capability detection | Handles unpredictable template structures | manifest + auto-detect + user override |
| Post-build anti-fingerprinting | Allows template reuse and caching | Seeded RNG on siteId, applied after build |
| Build isolation per template | Prevents npm cache conflicts, ensures reproducibility | `npm ci` in separate temp directories per format |
| Deterministic fingerprinting | Same siteId → identical output for audit trails | SHA256(siteId:namespace) → seedrandom |
| Quality checks as deploy gate | Fail fast before Cloudflare upload | Critical failures block deploy, warnings log only |
