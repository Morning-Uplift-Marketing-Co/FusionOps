## Template Prompt for Lovable / v0.dev

```
Create a loan affiliate landing page with React + Vite + Tailwind CSS.

=== WHAT YOU NEED TO BUILD ===

A single-page loan landing page. The build system handles tracking, apply page, and color switching automatically. You do NOT need to write any tracking code.

=== TEMPLATE ID ===

Follow naming convention: {source}-{niche}-{number}
Examples: lov-loan-01, lov-loan-02, lov-pet-01

=== STRUCTURE ===

Required files:
- package.json (with react, react-dom, vite, tailwindcss, @tailwindcss/vite or postcss)
- vite.config.ts (standard React+Vite config)
- tsconfig.json
- index.html (entry point with <div id="root">)
- src/main.tsx (React entry)
- src/App.tsx (main landing page -- THIS IS YOUR FOCUS)
- src/index.css (with @tailwind directives + CSS vars)

NOT needed (auto-generated by build pipeline):
- Apply page / form page -- BUILD PIPELINE GENERATES THIS
- Tracking scripts -- BUILD PIPELINE INJECTS THESE
- Voluum/pixel code -- BUILD PIPELINE INJECTS THESE
- public/apply.html -- DO NOT CREATE THIS

=== COLOR SYSTEM (CRITICAL) ===

DO NOT hardcode colors like bg-orange-500 or text-blue-600.
ALWAYS use CSS variable-based classes:

GOOD:  bg-primary, text-primary, border-primary, ring-primary
BAD:   bg-orange-500, text-blue-600, bg-emerald-100

For lighter/darker shades, use opacity:
  bg-primary/10, bg-primary/20, text-primary/70

Neutrals (slate, gray, white, black) are OK to hardcode.

=== index.css ===

```css
@tailwind base;
@tailwind components;
@tailwind utilities;

:root {
  --primary: <LEAVE EMPTY -- deploy system injects per-site>;
  --color-primary: <SAME AS --primary>;
  --secondary: <LEAVE EMPTY>;
  --accent: <LEAVE EMPTY>;
  --background: <LEAVE EMPTY>;
  --foreground: <LEAVE EMPTY>;
  --radius: 0.75rem;
}
```

DO NOT put real HSL values here. The deploy pipeline sets these via PUBLIC_COLORID.
Just declare the variable names so Tailwind can reference them.

=== tailwind.config.ts ===

```ts
export default {
  content: ['./index.html', './src/**/*.{ts,tsx,js,jsx}'],
  theme: {
    extend: {
      colors: {
        primary: { DEFAULT: 'hsl(var(--primary) / <alpha-value>)' },
        secondary: { DEFAULT: 'hsl(var(--secondary) / <alpha-value>)' },
        accent: { DEFAULT: 'hsl(var(--accent) / <alpha-value>)' },
        background: 'hsl(var(--background) / <alpha-value>)',
        foreground: 'hsl(var(--foreground) / <alpha-value>)',
      },
      borderRadius: { DEFAULT: 'var(--radius, 0.75rem)' },
    },
  },
};
```

=== LANDING PAGE REQUIREMENTS ===

1. Payment Calculator section:
   - Loan amount slider/buttons
   - Term selector
   - Monthly payment output with working JavaScript calculation
   - Heading MUST contain "Payment Calculator"

2. Representative APR table:
   - <table> element with at least 3 rows
   - Text "Representative APR" MUST appear

3. CTA button:
   - Links to /apply
   - Use bg-primary text-white styling

4. Regulatory disclosure section

5. Trust badges / social proof

6. Mobile-first responsive design

7. Sticky mobile CTA

=== OG IMAGE (for dashboard thumbnail) ===

Optional. If you have a preview image, add:
  <meta property="og:image" content="https://your-r2-bucket.r2.dev/og/template-name.png" />

Upload to Cloudflare R2 or any public CDN. If missing, dashboard shows gradient fallback.

=== DO NOT ===

- Do NOT hardcode colors (use bg-primary, text-primary, etc.)
- Do NOT create an apply/form page (build pipeline generates it)
- Do NOT create public/apply.html (build pipeline generates it)
- Do NOT add tracking/pixel/gtag scripts (build pipeline injects them)
- Do NOT use "guaranteed approval", "100% approval", "free money" copy
- Do NOT use Next.js -- use plain Vite + React
- Do NOT put real HSL values in CSS vars (deploy pipeline sets them)
```

## Import via FusionMCP

After creating the template in Lovable:

### Option 1: MCP Import (from Claude Code / Cursor)
```
Import Lovable project "Project Name" to FusionOps
name: "Template Name"
category: loan
```

AI will:
1. Read all files from Lovable project via Lovable MCP
2. Auto-generate ID as `lov-loan-XX` (auto-increment)
3. Save via FusionMCP `save_template`
4. Template appears in dashboard with LOVEABLE badge

### Option 2: Direct API (from Lovable terminal)
```js
async function saveFusionOpsTemplate() {
  const files = {
    'index.html': await readFile('index.html'),
    'src/App.tsx': await readFile('src/App.tsx'),
    'src/main.tsx': await readFile('src/main.tsx'),
    'src/index.css': await readFile('src/index.css'),
    'vite.config.ts': await readFile('vite.config.ts'),
    'tailwind.config.ts': await readFile('tailwind.config.ts'),
    'tsconfig.json': await readFile('tsconfig.json'),
    'package.json': await readFile('package.json')
  };

  const response = await fetch('https://fusion-mcp.misty-feather-556e.workers.dev/api/templates', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'x-mcp-secret': '<YOUR_MCP_SECRET>'
    },
    body: JSON.stringify({
      templateId: 'lov-loan-01',
      name: 'My Template',
      description: 'Created from Lovable',
      source: 'loveable',
      category: 'loan',
      files: files
    })
  });

  return await response.json();
}

saveFusionOpsTemplate();
```

### Option 3: Download ZIP + CLI Upload
```bash
node scripts/folder-to-template-json.js ./downloaded-lovable-project \
  --upload --name "My Template" --category loan --badge Loveable
```

## Quality Gate -- What Gets Checked on Import

These checks run when you import (template must pass):
- viewport meta tag present
- --primary CSS variable declared
- "Payment Calculator" section present
- Representative APR table present
- No banned copy ("guaranteed approval")
- Uses bg-primary not hardcoded colors

These are NOT checked on import (pipeline handles later):
- First-party pixel
- Google Ads tracking
- Voluum tracking
- apply page

## What the Build Pipeline Handles Automatically

| Concern | Handled By | When |
|---------|-----------|------|
| First-party pixel (GET beacon) | `inject-tracking.mjs` | CI build |
| Google Ads gtag | `inject-tracking.mjs` | CI build |
| Voluum dtpCallback | `inject-tracking.mjs` | CI build |
| Click ID capture (gclid, vlcid) | `inject-tracking.mjs` | CI build |
| /apply page (LeadsGate form) | `inject-tracking.mjs` | CI build |
| Color scheme (--primary, etc.) | `deploy-lp.yml` .env | CI build |
| e.ts, robots.txt.ts, _headers | `inject-tracking.mjs` | CI build |
| Anti-fingerprint transforms | `TemplateBuilder.js` | CI build |

Template creators only need to build a beautiful landing page using `bg-primary` / `text-primary` classes. Everything else is automatic.
