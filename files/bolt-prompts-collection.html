💡 เริ่มต้นที่นี่

คู่มือนี้จะช่วยคุณเลือกพร้อมต์ที่เหมาะสมและใช้งาน Bolt.new ให้ได้ผลลัพธ์ที่ดีที่สุด อ่านส่วน "เลือกพร้อมต์ที่เหมาะสม" ก่อนเริ่มใช้งาน

🎯 เลือกพร้อมต์ที่เหมาะสม

Decision Tree - ตัดสินใจง่าย ๆ

1. ต้องการภาษาไทยหรือไม่?
  ✅ ใช่ → ต้องการความเข้มงวดสูงสุดไหม?
     ✅ ใช่ → ใช้ "Thai Ultra-Strict"
     ❌ ไม่ → ใช้ "Thai Version"
  ❌ ไม่ → ไปข้อ 2

2. สร้างสำหรับโปรเจกต์นี้โดยเฉพาะ?
  ✅ ใช่ → ใช้ "Repo-Specific"
  ❌ ไม่ → ไปข้อ 3

3. ต้องอัปโหลดเข้าระบบ template บนเซิร์ฟเวอร์?
  ✅ ใช่ → ใช้ "Server Upload"
  ❌ ไม่ → ไปข้อ 4

4. สร้างเฉพาะ lead-generation page เท่านั้น?
  ✅ ใช่ → ใช้ "Ultra-Strict Lead-Gen"
  ❌ ไม่ → ไปข้อ 5

5. ต้องการพร้อมต์แบบกระชับ?
  ✅ ใช่ → ใช้ "Shorter"
  ❌ ไม่ → ใช้ "Generic Full"

🚀 ขั้นตอนการใช้งาน

ขั้นตอนที่ 1: เลือกพร้อมต์

  1. ใช้ Decision Tree ด้านบนเพื่อเลือกพร้อมต์ที่เหมาะสม
  2. คลิกที่แท็บพร้อมต์ที่ต้องการ
  3. อ่านคำอธิบายเพื่อยืนยันว่าตรงกับความต้องการ

ขั้นตอนที่ 2: คัดลอกพร้อมต์

  1. คลิกปุ่ม "📋 Copy Prompt"
  2. จะเห็นข้อความแจ้งเตือน "✅ คัดลอกพร้อมต์สำเร็จ!"
  3. พร้อมต์อยู่ใน clipboard แล้ว

ขั้นตอนที่ 3: ใช้ Bolt.new

  1. ไปที่ bolt.new
  2. เลือก Claude Agent (แนะนำสำหรับ production)
  3. วางพร้อมต์ที่คัดลอกมา
  4. วางคำขอเฉพาะของคุณด้านล่าง
  5. กด Send

💡 เคล็ดลับ

ถ้ายังไม่แน่ใจว่าจะใช้พร้อมต์ไหน: เริ่มจาก Generic Full → ถ้าต้องการผ่าน validation ของโปรเจกต์นี้ ใช้ Repo-Specific → ถ้า Bolt เพิ่มฟีเจอร์ที่ไม่ต้องการ ใช้ Ultra-Strict
